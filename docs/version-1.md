# 任务管家 1.0

网址：https://study-inbox-jasmine-nov12.leanrhubarb2.chatgpt.site

iPhone 优先的个人任务网页，所有者私有访问。静态入口为 `dist/index.html`，无需构建；使用静态 HTTP 服务器运行 `dist`。图片 OCR 需要 HTTP(S)，不支持直接双击 HTML 的 file 模式。

## 已实现

- **完成留存**：添加事项 → 标记完成 → 独立“已完成”页。保存完成时间、要求、原文与操作历史；可撤销完成或恢复待办。
- **任务管理**：学习/工作/生活/个人分类，普通/重要/紧急优先级，今天/3天内/逾期/无期限筛选，标题、课程、要求和来源搜索。
- **信息转入**：粘贴文字或选择最多5张 PNG/JPG/WebP 截图，单张不超过12MB。截图在本机识别，不上传到识别服务，不长期保存图片。
- **待确认**：规则拆分任务，保留原文、来源与原消息日期；身份相关性提示及筛选；支持批量确认。
- **日期**：绝对日期、今天/明天/后天、周几/下周几、中文时刻；多日期冲突待人工确认；支持只设置日期而不猜具体时刻。
- **合并**：核对同名/包含关系的相似任务，选择保留旧要求或采用新要求，保留双方原文。不同课程或不同编号不合并；已有完成事项不会被自动重新打开。
- **防误操作**：忽略事项可以恢复；删除先进入回收站，再明确选择永久删除。
- **数据**：localStorage 保存，兼容旧版任务；完整 JSON 备份可下载或复制，导入前预览并保留当前同 ID 任务。
- **日历**：有期限任务可导出为 iCalendar 文件，供日历应用导入。包含提前30分钟提醒，是否触发取决于日历应用设置。
- **手机入口**：主屏幕图标与 manifest。未实现离线启动服务，不承诺后台运行。

## 如何使用

1. 在“我的”中填写班级、课程、姓名、小组，并添加你实际需要的群来源。
2. 在“转入”中粘贴消息或选择截图，核对原消息日期和识别文字。不同事项用空行分隔。
3. 在“待确认”中检查期限、提交方式和对象，选择加入或合并。
4. 完成任务后点击“标记完成”，到“已完成”中查看留存记录。
5. 定期在“我的”中生成备份，并确认文件保存成功；下载被浏览器阻止时可复制完整备份文本。

## 数据与边界

所有任务存储在当前设备的当前浏览器，未实现云数据库同步。不同设备、本地文件与在线域名之间不会自动迁移，请使用备份转移。清理浏览器数据会删除记录。已完成记录不自动删除，但同样受浏览器存储限制。

任务整理使用本地规则，**不是云端 AI 理解**。没有接入学习通、微信或 QQ 自动读取，也没有网页后台推送。近7天转入记录只反映用户实际导入的信息，不代表已经扫描全部群消息。OCR 可能存在错字，所有草稿需核对后才进入待办。只设置日期的任务按当地当天结束判断逾期，所有日期按设备时区解释。

## 验证

通过：任务创建、完成留存和刷新、恢复待办、回收站恢复、忽略恢复、相似事项合并、搜索、JSON备份内容与合并恢复、真实中文图片OCR，以及5个页面在320/390/768/1440像素下的横向溢出检查。浏览器测试无未处理JS错误。

未验证：真实iPhone Safari设备、iOS日历导入与实际提醒。自动化Chrome环境下载出现取消，因此提供了复制完整备份的可用备用路径；用户仍应检查下载是否保存。

## OCR 依赖

Tesseract.js 7.0.0 与 Tesseract.js-core 7.0.0，Apache-2.0；语言数据来自 tesseract-ocr/tessdata_fast 的 chi_sim 与 eng。脚本、核心与语言数据全部随站点托管，首次识别时按需加载。许可证保存在 `dist/vendor/`。

官方参考：https://github.com/naptha/tesseract.js/blob/master/docs/api.md
语言数据：https://github.com/tesseract-ocr/tessdata_fast
